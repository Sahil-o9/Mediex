# 🏥 Mediex

> A modern, full-featured healthcare web application that empowers patients to manage their complete health journey in one unified platform.

Mediex streamlines healthcare management by connecting patients with doctors, hospitals, and essential health resources. Whether booking appointments, analyzing medical reports, or accessing health guidance, Mediex makes it simple and accessible.

---

## ✨ Features

- **Patient Management**
  - Secure patient registration and login
  - Comprehensive health profile management
  - Emergency contact information storage

- **Doctor Portal**
  - Doctor dashboard with practice management
  - Demo doctor access for testing
  - Patient appointment management

- **Healthcare Discovery**
  - Hospital and specialist search
  - Advanced filtering and discovery tools
  - Hospital details and location information

- **Appointment System**
  - Intuitive appointment booking interface
  - Doctor availability management
  - Appointment history and tracking

- **Medical Reports**
  - Medical report upload and analysis
  - Report history and organization
  - Secure document management

- **Health Assistant**
  - AI-powered health information guidance
  - General wellness recommendations
  - 24/7 health support

- **User Experience**
  - Fully responsive design (mobile, tablet, desktop)
  - Modern, intuitive interface
  - Fast and smooth interactions

## 🚀 Getting Started

### Prerequisites

- **Node.js** (v16 or higher recommended)
- npm or yarn package manager

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sahil-o9/Mediex.git
   cd Mediex
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   ```
   http://localhost:8080
   ```

## 🌐 Deployment

Deploy to **Vercel** in just a few clicks:

1. Visit [Vercel New Project](https://vercel.com/new)
2. Import the `Sahil-o9/Mediex` repository
3. Keep default build settings
4. Click **Deploy**

Your live application will be available at: `https://your-project-name.vercel.app`

## ⚠️ Important Note

**Mediex is a demonstration project.**

- Patient data is stored in **browser local storage** only
- Not connected to real hospital or medical databases
- Health assistant provides **general information only**
- Not intended for actual medical diagnosis or treatment
- For real medical needs, consult licensed healthcare professionals
